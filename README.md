# Blog Application – Full Stack Web Development

## Project Overview
A full-stack Blog Application developed using HTML, CSS, JavaScript, Node.js, Express.js, and MongoDB.

## Features
- User Registration and Login
- Create and View Blog Posts
- Edit and Delete Blog Posts
- Dashboard to manage blog activity
- MongoDB database integration
- REST API development
- Responsive frontend

## Technologies Used
- Frontend: HTML, CSS, JavaScript
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: bcryptjs

## Project Structure
- backend – Server and API files
- frontend – User interface files

## Run Locally
1. Install Node.js and MongoDB.
2. Open the backend folder in VS Code.
3. Run `npm install`.
4. Run `node server.js`.
5. Open `http://localhost:5000`.

## API Endpoints
- POST `/api/register`
- POST `/api/login`
- POST `/api/blogs`
- GET `/api/blogs`
- PUT `/api/blogs/:id`
- DELETE `/api/blogs/:id`
